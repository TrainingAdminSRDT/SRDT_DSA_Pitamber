# SRDT_DSA_Pitamber

This repository contains a collection of data structures and algorithms examples, organized for learning and practical use.

## Circular Queue

- `circular_queue.py`: A professional Python implementation of a fixed-size circular queue.
- Supports enqueue, dequeue, peek, and queue inspection.

## Usage

Run the circular queue example with:

```bash
python circular_queue.py
```
